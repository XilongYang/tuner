Cloud backup (Azure Blob Storage)

Backs up your saved history (text, scores, and recordings) straight from this browser to an Azure Blob Storage container you control — still no backend. You'll need a Storage Account with CORS enabled for this page's origin (allow GET, PUT, DELETE, OPTIONS) and a container-level SAS URL with read/write/list/delete permission. The SAS is stored only in this browser and is visible in the Network panel when used, same as your Speech key above. Storage and requests are billed on your Azure account.
